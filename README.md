# 📋 Work Logger
 
A clean, minimal daily work hour tracker that runs entirely in your browser — no backend, no account, no nonsense.
 
---
 
## ✨ Features
 
- **Log work hours** — pick a date, set start & end time with a one-tap "Now" button
- **Break tracking** — add multiple breaks per day, they're subtracted automatically
- **Weekly view** — see all entries for the current Mon–Sun week at a glance
- **Grand Total** — accumulated weekly hours calculated automatically
- **Shareable summary** — generates a clean copy-ready text for the selected day:
  ```
  29 Apr :-
  Working hours :- 12:44 pm to 7:44 pm
  Break :- NIL
  Total hours :- 7 hr
  
  Grand Total hours :- 40 hr 45 min
  ```
- **Auto weekly reset** — data clears itself every Monday, fresh start every week
- **Light / Dark theme** — toggle with one click, preference saved across sessions
- **Zero dependencies** — no npm, no build step, no frameworks
